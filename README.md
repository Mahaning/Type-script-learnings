# Type-script-learnings

A collection of TypeScript and JavaScript study notes, examples, practice problems, and reference material.

## Learning Path

Work through the folders and numbered Markdown files in order; each folder moves from introductory concepts toward more advanced material. Files ending in `_duplicate` are identical copies retained from the original collection.

1. [Environment Setup](01-Environment-Setup/) - Install TypeScript and prepare the development environment and tools.
2. [Core Fundamentals](02-Core-Fundamentals/) - Learn variables, data types, operators, control flow, loops, and core tools.
3. [Strings](03-Strings/) - Study string operations and practice problems.
4. [Functions](04-Functions/) - Progress from function basics through callbacks, overloading, and advanced examples.
5. [Arrays and Tuples](05-Arrays-and-Tuples/) - Explore arrays, iteration, higher-order methods, and tuples.
6. [Objects, Interfaces, and OOP](06-Objects-Interfaces-and-OOP/) - Learn objects, interfaces, classes, and inheritance.
7. [Reference](07-Reference/) - Keep the TypeScript cheatsheet nearby for review.
