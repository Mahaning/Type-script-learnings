# Type-script-learnings

A collection of TypeScript and JavaScript study notes, examples, practice problems, and reference material.

## Learning Path

Work through the folders in order. Files inside each folder are numbered to suggest a progression from introductory concepts to more advanced material.

1. [Setup](01-Setup/) - Install TypeScript and prepare the development environment.
2. [Fundamentals](02-Fundamentals/) - Learn variables, data types, operators, control flow, loops, and core tools.
3. [Functions](03-Functions/) - Progress from function basics through callbacks, overloading, and advanced examples.
4. [Strings](04-Strings/) - Study string operations and practice problems.
5. [Arrays and Tuples](05-Arrays-and-Tuples/) - Explore arrays, iteration, higher-order methods, and tuples.
6. [Objects and OOP](06-Objects-and-OOP/) - Learn objects, interfaces, classes, and inheritance.
7. [Reference](07-Reference/) - Keep the TypeScript cheatsheet nearby for review.
